# Hydrophone acoustic-pressure mapping

Needle-hydrophone spatial acoustic-pressure maps of the transducer field, in two scans:

- [`quasi2D_pdms_channel_scan/`](quasi2D_pdms_channel_scan/) — PDMS channel, 1.7 MHz / 20 Vpp, 19 points.
- [`3D_aneurysm_channel_scan/`](3D_aneurysm_channel_scan/) — aneurysm channel, 2 MHz / 30 Vpp, 24 points.

Both scans used the same Precision Acoustics needle hydrophone (SN 4746,
preamplifier HP34211, DC coupler DCPS0895) and calibration certificate 20251211-03.
See each sub-folder's README for scan-specific details, and the paper and its
supplementary note for full experimental context.
